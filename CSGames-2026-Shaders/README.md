`CSGames 2026 - Shaders`
----------------

Directeur de compétition: `Albin Calais`

Description préliminaire: `Programmation de shaders en glsl, reproduction d'images et d'effets visuels`


Résumé
----------------

Tout est décrit dans l'énoncé ([fr](./ENONCE-FR.md) / [en](./ENONCE-EN.md)). Dans les grandes lignes:
- Reproduction d'images à partir d'une base de code
- *Golfing* - réduire la taille d'un fichier au minimum sans en changer le comportement
- Epreuve libre de traitement d'image sur une vidéo
- Implémentation du jeu de la vie
- Implémentation du jeu Snake
- Un détour par le *path tracing*
- Un dernier challenge en 3D

Info communication
----------------

Il n'y a pas besoin de connaitre la programmation en shaders, ni glsl.\
Une bonne compréhension mathématique aidera mais il n'y a pas de niveau minimum à avoir.\
Interdiction d'utiliser l'IA ! Tout est suffisamment simple pour pouvoir être découvert pendant l'épreuve ou sur internet.

Info infra
----------------

Il y aura besoin d'un PC Windows par personne, idéalement avec un IDE (ex. Visual studio code + n'importe quelle extension qui supporte les shaders).\
Version glsl minimum supportée: 4.3 (sortie en 2014)\
Version java minimum supportée: JRE 16 (installable depuis [openjdk](https://jdk.java.net/25/))
